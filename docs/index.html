Ontology MCP

Turn ISO 20022 banking messages into a queryable knowledge graph — accessible to any AI agent via the Model Context Protocol.

pip install ontology-mcp && python mcp_server.py

The Problem

  • ISO 20022 is the global standard for financial messaging
  • Data is locked inside dense XML files
  • "Find all transactions over $50K involving BLUEUSNY" means grepping
  • Messages are interconnected but live in separate files
  • AI agents have no way to query the data
  • Ingests raw XML → extracts typed financial signals
  • Builds an RDF knowledge graph (Oxigraph or rdflib)
  • 10 MCP tools for natural language queries
  • Tracks full message lifecycles across pacs → camt chains
  • AI agents can ask questions in plain English

Architecture

ISO 20022
XML → Signal
Extraction → RDF
Mapping → MCP
Tools → AI Agent

Storage: Oxigraph (RocksDB persistent) · Fallback: rdflib (in-memory) · Transport: stdio MCP · Streaming: WebSocket

Available Tools

ToolDescription
extract_and_mapParse XML → signals → RDF, merge into graph
load_xml_fileLoad XML from disk and process it
load_output_directoryLoad all pre-built .ttl files from a folder
query_lifecycleFull message chain for a case/transaction/BIC
sparql_queryRun arbitrary SPARQL against the graph
find_anomaliesFlag high-value txns, rejected cancellations, mismatches
get_institution_activityAll messages for a BIC code with totals
graph_statsTriple count, signal breakdown, BIC inventory
start_stream_serverStart WebSocket server for streaming XML ingest
push_stream_messagePush XML over WebSocket in real-time

Example Queries

User: "What happened with cancellation case 20220718USDDSA9407803873?"
Agent: I found 4 messages in the lifecycle — pacs.008 initiated, camt.056 requested cancellation, camt.029 rejected (already settled), camt.026 notified unable to apply.

User: "Are there any anomalies?"
Agent: Found 4 high-value transactions (>$50K) and 1 rejected cancellation.
